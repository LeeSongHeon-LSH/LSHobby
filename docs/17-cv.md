## 17. CV 모듈 — **분리 완료 (2026-08-30, #73)**

공개 이력서는 더 이상 이 앱의 일부가 아니다. 별도 리포 **[`LeeSongHeon-LSH.github.io`](https://github.com/LeeSongHeon-LSH/LeeSongHeon-LSH.github.io)** 로 이관해 GitHub Pages로 서빙한다 — https://leesongheon-lsh.github.io

분리한 이유: CV는 **로그인도 DB도 필요 없는 문서 한 장**인데, 그 하나 때문에 앱 전체가 공개 표면(anon RLS 예외·색인 허용·정적 재검증 경로)을 떠안고 있었다. LSHobby 본체를 테일넷 안쪽으로 옮기면서(§16.5) 공개면과 사적 공간을 리포 단위로 갈랐다.

### 17.1 무엇이 어디로 갔나

| 이관 전 (LSHobby) | 이관 후 |
|---|---|
| `cv_document` 테이블 (anon SELECT 예외) | 리포의 **`cv.md`** — 마크다운 한 덩어리, git이 이력 관리 (테이블은 마이그레이션 `20260830080000`로 drop) |
| `/`·`/cv` 서버 렌더 + `/api/revalidate-cv` | `next build --output export` → `out/` → Pages. 서버 없음, 재검증 개념 없음 |
| `/cv/edit` (AuthGuard + textarea) | GitHub의 `cv.md` 편집 화면. LSHobby 쪽에서 나가는 링크는 두지 않는다 (#69) |
| 섹션 필터 칩·종이 시트·남극 장면 (#61·#65) | 그대로 이관 — 쓰는 도트 스프라이트 7종과 해당 CSS만 복사 |
| "마지막 수정" = `updated_at` 컬럼 | `cv.md`의 **마지막 커밋 시각** (빌드 때 `git log -1`, 그래서 Actions는 `fetch-depth: 0`) |

- 콘텐츠 성격은 그대로다: 이름·이메일·학위 등 기본 정보를 포함한 **마크다운 한 덩어리**, 한국어 단일, 전면 공개 + 색인 허용. `cv.md`가 비어 있으면 "CV 준비 중"만 보인다.
- `## 제목`이 곧 섹션 필터 칩이 된다 (무선택 = 전체, 재탭 = 전체 복귀).

### 17.2 라우팅 (LSHobby 쪽 개정)

| 경로 | 이관 전 | 이관 후 |
|---|---|---|
| `/` | 공개 CV (로그인 세션 있으면 `/home`) | **취미공간의 문** — 중앙에 큰 마스코트, 누르면 `/login`. 로그인 세션이 있으면 `/home`으로 replace(그대로) |
| `/cv`·`/cv/edit`·`/api/revalidate-cv` | 있음 | **삭제** |
| `/home` | 4서랍 | **3서랍**(책·언어·생각). CV 서랍은 잠깐 외부 링크로 남겼다가 #69에서 제거 |

- `/`는 이제 공개 문서가 아니라 테일넷 안에서만 열리는 주소라 **`robots: noindex`** 를 건다 (이관 전 "색인 허용"의 반전).

### 17.3 로그인 이스터에그 — 루트로 이관 (§17.6 계승)

- "마스코트를 누르면 로그인"은 **어떤 개편에서도 유지한다**는 원칙(2026-08-20 재확인)을 이번에도 지켰다. 위치만 공개 CV 상단 → **LSHobby 루트 중앙**으로 옮겼다.
- 이제 마스코트는 장식이 아니라 문 그 자체다 — 루트에 다른 요소가 없으므로 크게(160px) 놓는다. "로그인" 텍스트 링크를 두지 않는 것은 그대로.
- 새 CV 사이트에도 종이 시트 위 마스코트는 남아 있지만 **링크가 아니다** — 외부 공개면에 사설 주소를 노출하지 않는다.

### 17.4 배포

`main` 푸시 → GitHub Actions(`deploy.yml`: `npm ci` → `npm test` → `npm run build` → `upload-pages-artifact` → `deploy-pages`) → Pages. Pages 소스는 **"GitHub Actions"** 여야 한다 — 기본값인 legacy(Jekyll)로 두면 Jekyll이 README를 렌더한 페이지가 배포된다(2026-08-30 실제로 한 번 그렇게 나갔다).

### 17.5 남은 것 (이관 전 기록)

- 이관 전의 설계 근거(#51 "링크 = CV, 로그인 = 취미공간" 이중 구조, #61 비주얼 확정, #62 정적화)는 git 히스토리와 §10 결정표에 보존.
- 새 리포는 `shared/markdown`(rehype-sanitize)까지 복사해 갔으므로 SEC-05는 양쪽에서 유지된다. 다만 정적 export에는 `headers()`가 없어 **SEC-06 3종 헤더는 CV 사이트에 걸리지 않는다** — 공개 문서 한 장이고 로그인·입력이 없어 감수한다.
