## 17. CV 모듈 — 공개 이력서 페이지 (확정 2026-08-18 · 개정 2026-08-20, #60·#61)

앱의 대표 링크(`/`)로 들어온 외부인에게 **공개 이력서(CV)** 를 보여주고, 소유자는 로그인해 내용을 수정한다. 기존 취미공간(홈·3세션)은 로그인 뒤의 사적 영역으로 그대로 — **"링크 = CV, 로그인 = 취미공간"** 의 이중 구조 (#51).

### 17.1 성격과 공개 범위

- 콘텐츠: 이름·이메일·학위 등 기본 정보를 포함한 **마크다운 문서 한 덩어리** — 구조화 필드 없음 (#51). 한국어 단일.
- 공개: 전면 공개 + **검색엔진 색인 허용**. 이메일은 난독화 없이 그대로 노출 — 스팸은 메일 필터로 대응.
- 초기 콘텐츠는 빈 상태 — 본문이 비어 있는 동안 공개 페이지는 최소 표시("준비 중")만.

### 17.2 라우팅

| 경로 | 내용 | 가드 |
|---|---|---|
| `/` | 공개 CV. **로그인 세션이 있으면 `/home`으로 replace** | 없음 (anon 열람) |
| `/home` | 통합 홈(허브) — 기존 `/`에서 이사 | AuthGuard |
| `/cv` | 로그인 여부와 무관하게 항상 CV 표시 (본인 확인용 우회로) | 없음 |
| `/cv/edit` | CV 마크다운 편집 | AuthGuard |
| `/login` | 기존 그대로 — 성공 리다이렉트만 `/` → `/home` 변경 | |

- 하단 탭 3벌의 첫 슬롯 `[홈]` href `/` → `/home` 변경. §11.1 내비 문법 자체는 불변.
- 홈의 CV 편집 진입점: 세션 카드 3개 옆 **4번째 카드 `📄 CV`** → `/cv/edit` (#52).
- `/`의 로그인 리다이렉트는 **클라이언트 검사** — 세션이 브라우저(localStorage)에만 있어 서버는 로그인 여부를 모른다. 외부인·크롤러는 서버가 렌더한 CV HTML을 그대로 받으므로 색인에 영향 없음.

### 17.3 데이터 — `cv_document`

- 신규 `cv` 모듈이 소유하는 **1행 테이블** (DDL 원본은 §9.2): `id` / `content`(마크다운) / `updated_at`.
- **RLS 예외 (전 스키마에서 유일)**: 이 테이블만 `anon SELECT` 허용. 쓰기는 여전히 authenticated 전용 — SEC-02는 "cv_document 제외 anon 전부 거부"로 개정 (#51).
- CV 수정은 `activity_feed`에 **발행하지 않는다** — 취미 기록이 아닌 문서 관리이고, domain 값 체계(`'library'|'language'|'knowledge'`)를 건드리지 않기 위함.

### 17.4 렌더링

- `/`·`/cv`는 **첫 서버 컴포넌트 페이지** — 서버에서 anon 클라이언트로 읽어 HTML로 응답. **개정 (#62)**: `force-dynamic` → **정적 렌더 + 저장 시 `revalidatePath`**(`/api/revalidate-cv`, JWT 검증) — 수정 즉시 반영은 유지하면서 방문·크롤러 트래픽이 함수·DB를 태우지 않는다. service_role 불필요 (SEC-03 불변).
- 마크다운 렌더는 `shared/markdown` 재사용 (rehype-sanitize 포함 — SEC-05).
- 메타데이터: title은 이름 기반(예: "이송헌 — CV") + description 지정. robots 차단 없음.
- 디자인 — **개정 (2026-08-20, #61)**: "이력서 = 종이 한 장" — 눈밭 배경 위 종이 시트, 고운바탕 h1·괘선 h2, 링크는 잠옷 로즈. **섹션 필터 칩**(마크다운 h2 기준 클라이언트 토글 — 무선택=전체, 재탭=전체 복귀; 서버는 전체 렌더라 색인 불변). 비주얼 원본은 목업 아티팩트 「LSHobby 네 서랍 목업」.

### 17.5 편집 화면

- `/cv/edit`: CS 개념 편집(§11.6) 패턴 재사용 — textarea + 저장 버튼. 미리보기 토글 없음, 저장 후 `/cv`로 확인 (#52).

### 17.6 로그인 이스터에그

- 공개 CV 상단(종이 시트 위 모서리)에 **도트(픽셀아트) 마스코트 SVG** — #60 리테마로 고양이 → **펼친 책 위에 앉은 잠옷 모자 펭귄** (16×16 그리드, `shape-rendering: crispEdges`). **이 이스터에그는 어떤 개편에서도 유지한다** (유일한 로그인 진입점, 2026-08-20 재확인).
- **클릭 한 번 → `/login`** (#52). 별도 "로그인" 텍스트 링크는 두지 않는다 — 가입이 막혀 있어(SEC-01) 노출돼도 무해하지만, 외부인에게는 장식으로 보이는 것이 의도.

### 17.7 모듈 경계 (§15 반영)

- `cv` 모듈: 소유 테이블 `cv_document`. 의존은 `shared/auth`(편집 가드)와 `shared/markdown`(렌더)뿐 — reflection·tag·activity 미사용.
