## 11. 화면 와이어프레임 — 확정 (2026-08-14)

텍스트 와이어프레임. 목적은 **화면 인벤토리·요소·이동 경로의 확정**이며, 비주얼은 구현 단계에서 전면 재디자인(§6.5). 모바일 우선(§2.3) — 그림은 전부 모바일 폭 기준, PC는 같은 구조의 넓은 배치.

> **개정 (2026-08-20, #57~59)**: CS 세션 제거 · 인용구 삭제 · 책 세션 = 독서 여정 책장 · 탭바 [홈] 슬롯 폐지. §11.1·11.3·11.4(탭)·11.5는 개정 반영, §11.6은 사료. 비주얼·상호작용 원본은 목업 아티팩트 「LSHobby 네 서랍 목업」.
> **개정 (2026-08-30, #73·#69)**: CV가 별도 리포로 나가고(§17) 홈 CV 서랍도 제거 — 홈은 **책/언어/생각 3서랍**. §11.1·11.3 반영.

### 11.1 내비게이션 문법

```
로그인 ─→ 홈(허브) ─┬─→ 언어 세션 ─ 탭 [학습][단어장][통계][추가] · 우상단 [홈]
                    └─→ 책 세션   ─ 탭바 없음: 독서 여정 책장 · 우상단 [홈]
```

- **홈(허브)은 하단 탭바 없음** — 책/언어/생각 3서랍 화면(#53·#55·#57·#69)
- **개정(#59)**: 탭바의 `[홈]` 슬롯 폐지 — 홈 복귀는 **우상단 홈 버튼**(도트 서랍 아이콘, 도메인색 손잡이). 탭바에는 도메인 기능만 남는다
- **책 세션은 탭바 자체가 없음**(#58) — 독서 여정 책장이 단일 진입점. 세션 간 이동은 홈 경유 유지 — 세션 = 전용 공간(§5.1)
- 상세·편집 화면은 푸시 화면 — 상단 `←`로 복귀
- 키보드가 올라오면 탭바 숨김 (현행 앱 검증 패턴)

### 11.2 로그인 (공통)

```
┌──────────────────────────┐
│                          │
│         LSHobby          │
│                          │
│  [ 이메일             ]  │
│  [ 비밀번호           ]  │
│  [       로그인       ]  │
│                          │
└──────────────────────────┘
```

- Supabase Auth 이메일 로그인. **회원가입 UI 없음** — 1계정은 Supabase 대시보드에서 생성(§9.3)
- 세션 유지 중엔 이 화면을 건너뛰고 바로 홈

### 11.3 홈 (허브)

```
┌──────────────────────────┐
│ LSHobby              ⚙  │  ← ⚙ = 로그아웃·비밀번호 변경
│ ┌──────────────────────┐ │
│ │  🐧   책    완독 N권 │ │  ← 1×3 서랍 (데스크톱 3×1, #57)
│ └──────────────────────┘ │     서랍마다 도메인 펭귄 도트
│ ┌──────────────────────┐ │     (책=책 든 펭귄 · 언어=말풍선
│ │  🐧  언어   단어 N개 │ │      펭귄 · 생각=생각하는 펭귄)
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │  🐧  생각   기록 N개 │ │
│ └──────────────────────┘ │
└──────────────────────────┘
```

- 타임라인은 #53에서 제거됨(4등분 서랍) → #57로 CS 서랍이 빠지고, 생각 서랍이 붙었다가 #69로 CV 서랍이 빠져 **현행 3서랍(책·언어·생각)**
- 카드 서브텍스트는 **중립 보유량**(완독 N권·단어 N개) — 복습 수를 쓰지 않음 (§5.2 준수)

### 11.4 언어 세션

#### 11.4.1 학습 (세션 랜딩)

```
┌──────────────────────────┐
│ 언어 · 스페인어        ▾ │  ← 언어 전환 (영어 추가 후 활성)
│                          │
│     ┌──────────────┐     │
│     │   오늘 복습   │     │
│     │      23      │     │
│     │  [ 시작하기 ] │     │
│     └──────────────┘     │
│                          │
│  ( 🃏 새 단어 12개 보기 ) │  ← 칩: 새 단어 플래시 미리보기
│  ( 🔥 어려운 단어 5개 )   │  ← 칩: 집중 모드 퀴즈
│                          │
│  오늘 12단어 · 정답률 83% │
├──────────────────────────┤
│ [학습][단어장][통계][추가]  │
└──────────────────────────┘
```

- 현행 앱의 덱 화면 이식. 복습 0개면 덱은 "자유 연습" 문구로 전환(현행 동작)
- 칩은 해당 대상이 있을 때만 노출(현행 동작)
- **우상단 홈 버튼(#59)** — 학습·단어장·통계·추가 4화면 공통(퀴즈 화면은 `←`와 진행 카운터만)

#### 11.4.2 퀴즈

현행 3방향 그대로 이식(§6.5 기능 패리티): 스→한 타이핑 / 한→스 타이핑 / 예문이 있으면 **cloze 우선**. 채점 규칙은 언어 config(§6.2 — 스페인어: 모음 악센트 관대·ñ 엄격). 정답=Good, 오답=Again 자동 매핑(§6.3), 자가평가 버튼 없음.

```
문제 (한→스 예)                 정답 후
┌──────────────────────────┐  ┌──────────────────────────┐
│ ←            진행 7/23   │  │ ✓ 정답                   │
│                          │  │                          │
│         "사과"           │  │    la manzana            │
│                          │  │    사과                  │
│  [ español...         ]  │  │                          │
│  alt+모음→á  alt+n→ñ     │  │  例 Como una manzana     │
│                          │  │     cada día.            │
│  [        확인        ]  │  │     나는 매일 사과를…    │
├──────────────────────────┤  │                          │
│ (키보드 — 탭바 숨김)     │  │  [        다음        ]  │
└──────────────────────────┘  └──────────────────────────┘

cloze 변형: 문제 영역이
│  Como una ______ cada     │
│  día.        (뜻: 사과)   │
```

### 11.5 책 세션 — 개정 (2026-08-20, #58·#59)

책 세션은 탭바 없이 **독서 여정 책장 한 화면**이 서재를 겸한다. 상세 상호작용(펼침·넘김·시트)의 원본은 목업 아티팩트의 라이브 아트보드다.

#### 11.5.1 독서 여정 책장 (세션 랜딩 = 서재)

```
┌──────────────────────────┐
│ 서재 — 독서 여정    (홈) │  ← 우상단 홈 버튼 (#59)
│                          │
│ ▐제1보▌▐제2보▌…▐제5보▌  │  ← 책등 하나 = 한 보(步) = 완독 20권
│ ━━━━━━━━━━━━━━━━━━━━━  │     책등엔 펭귄 도트·권수 뱃지
│ ▐제6보▌ … ▐제N보▌┆다음┆ │  ← 진행중 보 + 점선 = 다음 보 예고
│ ━━━━━━━━━━━━━━━━━━━━━  │     (모바일 한 줄 5보, 데스크톱 10보)
│ [ ＋ 완독 기록 ]         │
└──────────────────────────┘
```

- 책등 탭 → 그 보가 **펼친 책**으로 열림: 목차 2쪽(여정 1~10 / 11~20) + 권당 속표지 1쪽(제목·저자·태그·완독일)
- 데스크톱 = 양면 스프레드(모서리 클릭 넘김), 모바일 = **한 쪽 넘김**(모서리·좌우 가장자리 탭, 실기기 스와이프)
- 펼친 책 헤더 `[← 책장 | 제N보 | 목차]` — 목차 버튼으로 어느 쪽에서든 목차 복귀

#### 11.5.2 완독 기록 플로우 (§7.2)

```
1단계: 책 선택            2단계: 회독 기록
┌──────────────────────┐  ┌──────────────────────┐
│ 완독 기록            │  │ 니코마코스 윤리학    │
│ [ 🔍 제목 검색     ] │  │                      │
│ · 니코마코스 윤리학  │  │ 완독일 [2026-08-14]  │  ← 기본 오늘
│   (기존 → 회독 +1)   │  │ 별점   ☆☆☆☆☆ (선택) │
│ · ＋ 새 책 등록      │  │                      │
│   └ 제목/저자/       │  │ [     기록 완료    ] │
│     옮긴이(선택)/    │  └──────────┬───────────┘
│     출판사/원저연도  │             ▼
└──────────────────────┘   여정 자세히보기로 — 노트·
                           reflection(감상)은 거기서
                           자유롭게 (순서 강제 없음)
```

- reflection을 이때 쓰면 `context`에 "N회독" 자동 기입(§7.2)

#### 11.5.3 자세히보기 시트 (구 "책 상세" 대체, #58)

```
┌──────────────────────────┐
│ My Notes · 여정 7/20  ✕ │  ← 데스크톱 = 종이 시트,
│ 니코마코스 윤리학        │     모바일 = 바텀시트
│──────────────────────────│
│ 1회독 · 2025.11          │
│  처음엔 '만족'으로       │  ← 회독별 감상만 —
│  읽었다…                 │     인용 블록 없음 (#58)
│ 2회독 · 2026.03          │
│  지금은 활동으로 읽힌다… │
│──────────────────────────│
│ [ ＋ 재독 기록 추가 ]    │
└──────────────────────────┘
```

- 감상 = reflection(§4, append-only) — 오래된 순, 수정·삭제 UI 없음(§11.7 문법 그대로)
- 메타데이터 수정·노트(§7.1) 진입 지점은 구현 시 확정

#### 11.5.4 인용구 — **폐기 (2026-08-20, #58)**

인용구를 기록하지 않기로 함 — 책 횡단 인용구 화면·책 상세 인용구 섹션 삭제.

### 11.7 공통 컴포넌트 — reflection 블록

책 상세·개념 상세(·추후 단어 상세) 하단에 동일하게 붙는 블록. shared 모듈이 렌더링 소유.

```
│ 생각 타임라인            │
│ ┌──────────────────────┐ │
│ │ 2025.03 · 1회독      │ │  ← context (§4.4)
│ │ 처음엔 행복을 상태로 │ │
│ │ 이해했다…            │ │
│ ├──────────────────────┤ │
│ │ 2026.08 · 2회독      │ │
│ │ 지금은 활동으로      │ │
│ │ 읽힌다…              │ │
│ └──────────────────────┘ │
│ [ ＋ 지금 생각 추가 ]    │
```

- 입력: 본문 + context 한 줄(선택, 책 완독 플로우에선 "N회독" 자동)
- **항목 수정·삭제 UI 없음** — append-only(§4.2)가 UI 레벨에서도 지켜짐
