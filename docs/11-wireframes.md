## 11. 화면 와이어프레임 — 확정 (2026-08-14)

텍스트 와이어프레임. 목적은 **화면 인벤토리·요소·이동 경로의 확정**이며, 비주얼은 구현 단계에서 전면 재디자인(§6.5). 모바일 우선(§2.3) — 그림은 전부 모바일 폭 기준, PC는 같은 구조의 넓은 배치.

### 11.1 내비게이션 문법

```
로그인 ─→ 홈(허브) ─┬─→ 언어 세션 ─ 탭 [홈][학습][단어장][통계][추가]
                    ├─→ 책 세션   ─ 탭 [홈][서재][인용구]
                    └─→ CS 세션   ─ 탭 [홈][개념]
```

- **홈(허브)은 하단 탭바 없음** — 세션 카드 + 타임라인만 있는 스크롤 화면
- **세션 진입 시 하단 탭바 등장**, 첫 슬롯은 항상 `[홈]`(허브 복귀). 세션 간 이동은 홈 경유 — 세션 = 전용 공간(§5.1)
- 탭 수는 세션마다 다르지만(5/3/2) 문법은 동일: 첫 슬롯 홈, 생성 진입은 마지막 탭 또는 화면 내 `＋`
- 상세·편집 화면은 탭바 위에 쌓이는 푸시 화면 — 상단 `←`로 복귀
- 키보드가 올라오면 탭바 숨김 (현행 앱 검증 패턴)

### 11.2 로그인 (공통)

```
┌──────────────────────────┐
│                          │
│         LSHobby          │
│                          │
│  [ 이메일             ]  │
│  [ 비밀번호           ]  │
│  [       로그인       ]  │
│                          │
└──────────────────────────┘
```

- Supabase Auth 이메일 로그인. **회원가입 UI 없음** — 1계정은 Supabase 대시보드에서 생성(§9.3)
- 세션 유지 중엔 이 화면을 건너뛰고 바로 홈

### 11.3 홈 (허브)

```
┌──────────────────────────┐
│ LSHobby              ⚙  │  ← ⚙ = 로그아웃
│                          │
│ ┌──────────────────────┐ │
│ │ 📚 책       완독 N권 │ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 🗣 언어     단어 N개 │ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 💻 CS       개념 N개 │ │
│ └──────────────────────┘ │
│                          │
│ 최근 기록                │
│ · 어제  단어 12개 복습,  │
│         정답률 83%       │
│ · 어제  「니코마코스     │
│   윤리학」 2회독 ★5     │
│ · 3일전 Raft 합의 정리   │
│   갱신                   │
│   ⋮ (스크롤 시 추가 로드)│
└──────────────────────────┘
```

- 카드 서브텍스트는 **중립 보유량**(완독 N권·단어 N개·개념 N개) — 언어 카드에 복습 수를 쓰지 않음 (§5.2 "홈 복습 배지 없음" 준수)
- 타임라인 = `activity_feed` 최신순. 항목 탭 → 해당 엔티티 상세로 이동, 원본이 삭제된 이벤트는 비활성 표시(§9.3)

### 11.4 언어 세션

#### 11.4.1 학습 (세션 랜딩)

```
┌──────────────────────────┐
│ 언어 · 스페인어        ▾ │  ← 언어 전환 (영어 추가 후 활성)
│                          │
│     ┌──────────────┐     │
│     │   오늘 복습   │     │
│     │      23      │     │
│     │  [ 시작하기 ] │     │
│     └──────────────┘     │
│                          │
│  ( 🃏 새 단어 12개 보기 ) │  ← 칩: 새 단어 플래시 미리보기
│  ( 🔥 어려운 단어 5개 )   │  ← 칩: 집중 모드 퀴즈
│                          │
│  오늘 12단어 · 정답률 83% │
├──────────────────────────┤
│ [홈][학습][단어장][통계][추가]│
└──────────────────────────┘
```

- 현행 앱의 덱 화면 이식. 복습 0개면 덱은 "자유 연습" 문구로 전환(현행 동작)
- 칩은 해당 대상이 있을 때만 노출(현행 동작)

#### 11.4.2 퀴즈

현행 3방향 그대로 이식(§6.5 기능 패리티): 스→한 타이핑 / 한→스 타이핑 / 예문이 있으면 **cloze 우선**. 채점 규칙은 언어 config(§6.2 — 스페인어: 모음 악센트 관대·ñ 엄격). 정답=Good, 오답=Again 자동 매핑(§6.3), 자가평가 버튼 없음.

```
문제 (한→스 예)                 정답 후
┌──────────────────────────┐  ┌──────────────────────────┐
│ ←            진행 7/23   │  │ ✓ 정답                   │
│                          │  │                          │
│         "사과"           │  │    la manzana            │
│                          │  │    사과                  │
│  [ español...         ]  │  │                          │
│  alt+모음→á  alt+n→ñ     │  │  例 Como una manzana     │
│                          │  │     cada día.            │
│  [        확인        ]  │  │     나는 매일 사과를…    │
├──────────────────────────┤  │                          │
│ (키보드 — 탭바 숨김)     │  │  [        다음        ]  │
└──────────────────────────┘  └──────────────────────────┘

cloze 변형: 문제 영역이
│  Como una ______ cada     │
│  día.        (뜻: 사과)   │
```

#### 11.4.3 단어장

```
┌──────────────────────────┐
│ 단어장                   │
│ [ 🔍 단어·뜻 검색      ] │
│ 218단어                  │
│                          │
│ la manzana   사과   복습 │  ← 우측 = FSRS 상태 뱃지
│ el país      나라   신규 │     (신규/학습중/복습/재학습)
│ año          해     복습 │
│  ⋮                       │
├──────────────────────────┤
│ [홈][학습][단어장][통계][추가]│
└──────────────────────────┘
```

- 행 탭 → 하단 시트: 단어·뜻·성별 편집 / 삭제 (현행 동작). 삭제 시 부속 데이터 cascade + reflection·activity는 §9.3 규칙
- 성별은 el/la 관사 표기로 노출 (현행 문법)

```
1단계: 책 선택            2단계: 회독 기록

│ 완독 기록            │  │ 니코마코스 윤리학    │

│   (기존 → 회독 +1)   │  │ 별점   ☆☆☆☆☆ (선택) │
│ · ＋ 새 책 등록      │  │                      │
│   └ 제목/저자/       │  │ [     기록 완료    ] │
│     옮긴이(선택)/    │  └──────────┬───────────┘
│     출판사/원저연도  │             ▼
└──────────────────────┘   책 상세로 이동 — 인용구·
                           노트·reflection은 거기서

```

- reflection을 이때 쓰면 `context`에 "N회독" 자동 기입(§7.2)

### 11.7 공통 컴포넌트 — reflection 블록

책 상세·개념 상세(·추후 단어 상세) 하단에 동일하게 붙는 블록. shared 모듈이 렌더링 소유.

```
│ 생각 타임라인            │
│ ┌──────────────────────┐ │
│ │ 2025.03 · 1회독      │ │  ← context (§4.4)
│ │ 처음엔 행복을 상태로 │ │
│ │ 이해했다…            │ │
│ ├──────────────────────┤ │
│ │ 2026.08 · 2회독      │ │
│ │ 지금은 활동으로      │ │
│ │ 읽힌다…              │ │
│ └──────────────────────┘ │
│ [ ＋ 지금 생각 추가 ]    │
```

- 입력: 본문 + context 한 줄(선택, 책 완독 플로우에선 "N회독" 자동)
- **항목 수정·삭제 UI 없음** — append-only(§4.2)가 UI 레벨에서도 지켜짐
- 오래된 순 정렬(위 → 아래로 생각의 변화가 읽히도록)

### 11.8 화면 인벤토리 요약

| 세션 | 화면 | 컷오버 포함(§6.5) |
|---|---|---|
| 공통 | 로그인 | ✅ |
| 홈 | 허브(카드 + 타임라인) | ✅ (골격) |
| 언어 | 학습 · 퀴즈 · 단어장 · 통계 · 추가 | ✅ 전부 |
| 책 | 서재 · 완독 기록 플로우 · 책 상세 · 인용구 | 컷오버 후 |
| CS | 개념 목록 · 상세 · 편집 | 컷오버 후 |
| 공통 | reflection 블록 | ✅ (골격) |
