## 7. 책 모듈 설계 — 확정 (2026-08-14) · 개정 (2026-08-20, #58·#59)

> **개정 요약**: 인용구(quote) 기능 삭제 · 서재 = 독서 여정 책장 · 구 "책 상세" 화면 폐지(여정 "자세히보기" 시트로 대체) · 책 세션 탭바 없음. 데이터 모델의 book·reading·노트·reflection과 §7.2 완독 기록 플로우는 유지.

### 7.1 데이터 모델

- **`book`**: 제목 / 저자 / 옮긴이(선택) / 출판사 / 원저 발표연도 — 전부 텍스트. **표지 이미지 없음** (철학 번역서 중심이라 표지의 정체성이 약하고, 필요해지면 nullable 컬럼 추가로 확장 가능)
- **등록**: 수기 입력만 — 외부 책 검색 API 사용 안 함 (표지를 버리면 자동채움의 실익이 텍스트 4~5필드뿐이라 마찰이 충분히 작음. 등록이 귀찮아지면 카카오 책 검색 추가 검토 — 스키마 영향 0)
- **등록 범위**: **완독한 책만** (§1.1 "탐독한 책 목록"). 위시리스트·"읽는 중"·"중단" 같은 독서 상태 없음. 필요해지면 "회독 0회 책 = 읽을 예정"으로 비용 없이 확장 가능
- **장르**: 자유 태그 — `shared/tag` 재사용. 고정 ENUM 없음. "스페인어 원서 = 책 + 언어" 같은 교차 케이스도 태그로 해결
- **`reading` (회독)**: 완독 이벤트만 기록 — `book_id`, `finished_on`(미입력 시 기록일), `rating`(선택, ★1~5). 시작일·상태 없음. 재독 = 새 레코드 → "1회독 ★3 (2025.3) → 2회독 ★5 (2026.8)"이 데이터로 남음
- **`quote` (인용구)**: **폐기 (2026-08-20, #58)** — 인용구를 기록하지 않기로 함(실사용 판단: 기억해두지 않을 것). 테이블은 코드 반영 시 DDL(§9)에서 제거
- **노트**: 책당 마크다운 노트 1개, 자유 수정 — 정적 요약(줄거리·구조 정리)용. append-only인 reflection이 못 하는 "다듬기"를 담당
- **reflection**: book 단위 스레드(shared 기능 그대로, `subject_type='book'`). 인용구 단위 스레드는 만들지 않음 (필요 시 subject_type 추가로 확장)

### 7.2 워크플로 — 완독 후 일괄 기록

중간 기록은 하지 않는다. 책을 전부 읽은 뒤에만 기록한다.

```
책을 다 읽음
  → (첫 회독이면) 책 등록
  → 회독 +1 (완독일 자동)
  → 별점 (선택)
  → 노트·reflection(감상) 작성 (선택, 순서 자유)
```

- reflection entry의 `context`에 **"N회독" 자동 기입** — 회독 기록과 생각 타임라인이 맞물림
- activity_feed 발행: 등록/완독/노트 갱신 전부 **건별** (책은 저빈도 도메인이라 도배 위험 없음 — 언어 모듈의 일별 요약과 굵기가 다른 것은 의도)
- 책 삭제 시 회독·노트·reflection 스레드 함께 삭제

### 7.3 화면 — 개정 (2026-08-20, #58·#59)

- 서재 = **독서 여정 책장**: 완독 20권 = 한 보(步) = 책등 하나. 책등을 펼치면 목차 + 권당 속표지 1쪽(제목·저자·태그·완독일). 데스크톱 양면 스프레드·모바일 한 쪽 넘김. 탭바 없음, 홈 복귀는 우상단 버튼(#59)
- 상세 = 여정 **"자세히보기" 시트**: 회독 이력 + 회독별 감상(reflection, 인용 블록 없음) + 재독 기록 추가. 구 "책 상세" 화면·인용구 화면은 폐기. 노트(§7.1)의 진입 지점은 구현 시 확정
- 와이어프레임 §11.5, 비주얼 원본은 목업 아티팩트 「LSHobby 네 서랍 목업」

### 7.4 인지된 트레이드오프

- **완독 전의 책을 앱이 전혀 모른다** — 홈 타임라인에도 완독 시점에야 나타남. "전부 읽은 뒤 기록" 철학에 따른 의도된 선택 (2026-08-14 확인)
- §5.4 초안의 "책 카드 그리드"는 표지 폐기로 타이포그래피 리스트로, 그 리스트는 다시 독서 여정 책장(#58)으로 대체됨
- **인용구 없이 감상만 남는다** — 완독 직후 한 줄 감상이 기록의 최소 단위 (2026-08-20 확인)
